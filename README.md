# Gerenciador de Condomínio

Sistema web para gestão de condomínios residenciais, com foco em comunicação, reservas de áreas comuns e controle de acesso.

---

## Funcionalidades

- **Ocorrências** — moradores registram problemas e elogios; up vote indica prioridade ao síndico
- **Fórum** — canal oficial top-down; só o síndico posta; avisos críticos ficam fixados no topo
- **Wiki** — base de conhecimento do condomínio: regulamentos, contatos e procedimentos internos
- **Reservas de áreas comuns** — agendamento para a semana corrente com verificação de conflitos
- **Código de acesso** — gerado automaticamente após a confirmação da reserva
